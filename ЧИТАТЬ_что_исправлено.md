# Исправление: повторная проверка !LATEST не видела изменённые файлы

## Причина

`docflow/latest.py` сравнивал `4300_ПД` и `!LATEST` **только по дате папки
версии** ({обозначение}_{ггммдд}). Если файл в 4300_ПД переписали/поправили
внутри той же папки версии (дату не меняли) — программа видела ту же дату
и в !LATEST, и молча считала документ «🟢 в порядке», хотя содержимое уже
другое.

В `docflow/transfer.py` (сравнение субподрядчик → сервер) такая проверка уже
была — CRC32-сверка состава и содержимого файлов при совпадающей дате версии
(статус 🟣 DIFF). Просто не была продублирована в `latest.py`.

## Что изменено

1. **`docflow/latest.py`**
   - Импортирована `crc_diff` из `transfer.py`.
   - Добавлен статус `DIFF = "🟣"`.
   - В `compare()`: если дата версии в !LATEST совпадает с датой в 4300_ПД,
     теперь дополнительно сверяются CRC32 всех файлов исходной папки и папки
     в !LATEST. При расхождении (файл переписан/добавлен/удалён) статус
     меняется на 🟣, в строку кладётся `diff` с деталями.

2. **`app.py`** (диалог «Комплект !LATEST»)
   - Строки со статусом 🟣 теперь тоже считаются «требующими обновления»
     (доступна галочка, попадают в счётчик наверху).
   - Легенда под кнопками дополнена расшифровкой 🟣.
   - Двойной клик по строке со статусом 🟣 показывает список файлов:
     изменённые / есть только в 4300_ПД / есть только в !LATEST.

3. **`docflow/__init__.py`** — версия поднята **1.11.1 → 1.11.2**,
   дата сборки обновлена на 2026-07-19. Номер отображается в заголовке
   окна и в «О программе».

4. **`CHANGELOG.txt`** — добавлена запись v1.11.2 с описанием исправления.

## Как применить

Замените в вашей копии программы (`_ПрограммаКомплектование`) четыре файла
на приложенные:

```
_ПрограммаКомплектование/app.py               ← заменить
_ПрограммаКомплектование/docflow/latest.py    ← заменить
_ПрограммаКомплектование/docflow/__init__.py  ← заменить
_ПрограммаКомплектование/CHANGELOG.txt        ← заменить
```

Затем:
- если запускаете через **`run.bat`** — просто запустите заново, ничего
  пересобирать не нужно;
- если пользуетесь собранным **`DocFlow.exe`** — нужно пересобрать: двойной
  клик по **`build_exe.bat`**, дождаться «ГОТОВО», новый `dist\DocFlow.exe`
  раздать помощникам.

## Проверка

1. Откройте документ, версия которого уже лежит в !LATEST (🟢).
2. Замените/подправьте PDF внутри той же папки версии в `4300_ПД`
   (дату папки не меняя).
3. В диалоге «Комплект !LATEST» нажмите «🔄 Сравнить» — документ должен
   показать статус 🟣, а не 🟢. Двойной клик по строке покажет, какой именно
   файл изменился.
4. Отметьте галочкой и нажмите «Обновить» — !LATEST подтянет новую версию.
